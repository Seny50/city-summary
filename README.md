# Сводка по городу

CLI-утилита получает текущую погоду для города через Open-Meteo и курс выбранной
валюты к рублю через Frankfurter. Затем она добавляет правила: совет тёплой
одежды при температуре ниже нуля и флаг дорогого курса при значении выше 100 RUB.

## Требования

- Python 3.12+
- доступ в интернет для запуска с реальными API

## Установка

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Запуск

Курс USD используется по умолчанию:

```bash
python main.py --city Moscow
```

Другой ISO-код валюты:

```bash
python main.py --city Moscow --currency EUR
```

JSON для интеграций:

```bash
python main.py --city Moscow --currency EUR --json
```

## Коды выхода

- `0` — сводка получена;
- `2` — неверные аргументы;
- `3` — город или код валюты не найден;
- `4` — внешний сервис недоступен либо вернул непригодный ответ после повторов.

Каждый HTTP-запрос является GET-запросом с timeout 8 секунд. Временные ошибки
подключения, ответы 500/502/503/504 и 429 повторяются до трёх попыток; для 429
используется числовое значение заголовка `Retry-After`. Курс валюты кэшируется в
памяти на пять минут.
